# TruthAI

Simple AI vs human text detector.

## Features

- Detects if text is AI or human
- Shows verdict, likelihood, and explanation
- Supports uploads (.txt, .pdf, .docx)
- Word count validation

## Usage

1. Paste text or upload a file
2. Click "See Results"
3. View analysis

## Live

https://truthai.online

## Notes

- Uses Gemini API for analysis
- Requires minimum word count
